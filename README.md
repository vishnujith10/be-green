🌱 BeGreen – Microgreens E-commerce Website
Overview

BeGreen is a real-world client project developed for a local microgreens business. The website enables customers to explore products, view detailed nutritional information, and place orders through WhatsApp. It also includes a secure admin dashboard for managing products and inventory.

Project Type: Client Project (Freelance)
Status: Completed & Deployed

> **Note**
>
> This repository contains a real-world freelance project developed for a client. Some business assets, credentials, and deployment configurations are omitted for privacy and security.
